# [Backend] Задание 1 — основы Python

Демонстрация базового синтаксиса Python на предметной области
салона «БРИТВА»: переменные и типы, коллекции, функции,
`dataclass`, обработка ошибок, работа с датами.

## Файлы

| Файл | Что внутри |
|---|---|
| `solution.py` | Всё решение одним файлом, 7 разделов |

## Запуск

```bash
python solution.py
```

Внешних зависимостей нет — только стандартная библиотека.

## Что демонстрируется

| Раздел `solution.py` | Тема |
|---|---|
| 1 | Переменные и типы: `str`, `int`, `bool`, `float` |
| 2 | Коллекции: список услуг, словарь мастеров, множество названий, кортеж часов работы |
| 3 | Функции: поиск услуги, сумма набора, фильтрация мастеров по услуге, форматирование цены |
| 4 | `@dataclass Appointment` со свойствами `service`, `ends_at`, `price` и методом `overlaps()` |
| 5 | Обработка ошибок: своё исключение `SlotBusyError`, проверки при создании записи |
| 6 | Итог: сколько записей создано и на какую сумму |
| 7 | Генератор свободных слотов мастера на день |

## Какие проверки выполняет `book()`

Перед созданием записи `book()` убеждается, что:

1. услуга с таким `service_id` существует;
2. мастер есть в справочнике;
3. мастер оказывает эту услугу;
4. время попадает в рабочие часы (09:00–21:00);
5. время не в прошлом;
6. у мастера нет другой записи, пересекающейся по времени.

При нарушении любого условия поднимается `SlotBusyError`
с понятным текстом.

## Ожидаемый вывод

В конце скрипт печатает две созданные записи и список свободных
слотов мастера. Пример:

```text
--- Итог ---
Записей создано: 2
Общая сумма: 2 300 ₽
1. 21.11.2026 10:00 — Никита к Алиса Морозова: Стрижка (1 500 ₽)
2. 21.11.2026 10:30 — Олег к Даниил Ковалёв: Стрижка бороды (800 ₽)
```

Даты зависят от текущей даты: записи создаются на «завтра».

## Особенности на Windows

Консоль Windows по умолчанию работает в cp1251 и не умеет печатать
символ `₽` — скрипт падал с `UnicodeEncodeError`. В начале
`solution.py` стандартный вывод переключается на UTF-8:

```python
if hasattr(sys.stdout, "reconfigure"):
    sys.stdout.reconfigure(encoding="utf-8", errors="replace")
```

Если печатать в перенаправленный файл, символ останется корректным.
