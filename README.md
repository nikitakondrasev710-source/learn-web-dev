# Основы web-разработки — учебный репозиторий

Репозиторий по курсу «Основы web-разработки». Четыре модуля:
Frontend, Backend, Проектирование и Тестирование.

---

## Модуль Frontend

Для каждой темы — три папки:

| Папка | Что внутри |
|---|---|
| `frontend-N-practice` | Задание студенту: README и заготовка |
| `frontend-N-lesson` | Пример, разобранный на лекции |
| `frontend-N-complete` | Полное приложение целиком |

Где `N` — номер темы: 1, 2, 3 или 4.

**`frontend-1` — Вёрстка**
HTML и CSS. Страница «Выбор даты и времени» по своему макету. Без JavaScript.

**`frontend-2` — Нативный JavaScript**
Та же страница, оживлённая на чистом JS: клики, переключение месяцев, выбор слота.

**`frontend-3` — React**
Перевод страницы на React: компоненты, `useState`, JSX. Запуск через Vite.

**`frontend-4` — React + сервер**
Подключение имитационного сервера: данные приходят через `fetch`,
появляются состояния загрузки и ошибки.

## Модуль Backend

Решения по заданиям модуля Backend лежат в папках `backend-N-practice`:

| Папка | Задание | Что внутри |
|---|---|---|
| `backend-1-practice/solution.py` | Задание 1 — основы Python | Синтаксис, коллекции, функции, dataclass, обработка ошибок |
| `backend-2-practice/solution.py` | Задание 2 — Web API на FastAPI | REST API: услуги, мастера, записи; GET/POST/DELETE, валидация, коды ответов |
| `backend-3-practice/solution.py` | Задание 3 — SQLAlchemy и Alembic | Модели, связи, миграции, запросы через ORM |
| `backend-4-practice/solution.py` | Задание 4 — Pydantic | APIRouter, схемы, кастомные валидаторы, бизнес-правила |

В каждой папке есть свой `README.md` с инструкцией по запуску.

Быстрый старт для `backend-2-practice`:

```bash
cd backend-2-practice
pip install fastapi uvicorn
uvicorn solution:app --reload
# http://127.0.0.1:8000/docs
python check_api.py   # автопроверка: 35 passed
```

## Предметная область

В примерах — запись клиента в салон услуг (барбершоп «БРИТВА»).
Это не обязательная тема: у каждого свой макет и своя предметная область.
Пример показывает **как** решать задачи, а не **что** писать.

## Требования

- Node.js 18+ — для тем `frontend-3` и `frontend-4`.
- Браузер — для тем `frontend-1` и `frontend-2`.
- Python 3.10+ — для модуля Backend.
