## BUG-001. При листании месяца назад выбранным остаётся прошедший день

| Поле | Значение |
|---|---|
| **Приоритет** | Major |
| **Серьёзность** | Средняя |
| **Окружение** | Chrome 157, Windows 11, http://localhost:3102 |
| **Компонент** | Календарь (React-версия) |
| **Предусловие** | «Сегодня» = 19.11.2026, выбран день 25 |

**Шаги воспроизведения**
1. Открыть страницу «Выбор даты и времени».
2. Нажать стрелку «‹» — перейти в октябрь 2026.
3. Посмотреть, какой день выделен.

**Ожидаемый результат:** выбранным становится первый доступный день
месяца (1 ноября), либо день, который не в прошлом.

**Фактический результат:** выбранным остаётся число 25, хотя весь
октябрь уже прошёл. В нижней панели отображается «25 октября» —
дата, на которую записаться невозможно.

**Причина:** при смене месяца состояние `selectedDay` не проверялось
на доступность в новом месяце.

**Исправление:** добавлена функция `normalizeSelectedDay()`, которая
при листании подбирает первый доступный день месяца
(`tests` — ручная проверка TC-08).

**Статус:** Исправлен, проверен.

## BUG-002. «Загрузка слотов…» мигает и не соответствует фактической загрузке

| Поле | Значение |
|---|---|
| **Приоритет** | Minor |
| **Серьёзность** | Низкая |
| **Окружение** | Chrome 157, http://localhost:3103 |
| **Компонент** | Блок слотов (React + сервер) |

**Шаги воспроизведения**
1. Открыть страницу.
2. Быстро кликнуть по трём разным дням подряд.

**Ожидаемый результат:** слоты отображаются только для последнего
выбранного дня; ответы на предыдущие запросы игнорируются.

**Фактический результат:** при медленном ответе сервера (500 мс)
мог отрисоваться набор слотов от предыдущего дня — расхождение даты
в заголовке и содержимого списка.

**Причина:** ответы приходили не в порядке отправки запросов.

**Исправление:** в эффекте загрузки слотов добавлена проверка
`data.date` — если ответ относится к другой дате, он отбрасывается.

**Статус:** Исправлен, проверен (TC-15).

## BUG-007. Ошибка сборки Vite: посторонний PostCSS-конфиг

| Поле | Значение |
|---|---|
| **Приоритет** | Blocker |
| **Серьёзность** | Высокая |
| **Окружение** | frontend-3-practice, Vite 8 |

**Шаги воспроизведения**
1. `npm run dev` в `frontend-3-practice`.
2. Открыть http://localhost:3001.

**Ожидаемый результат:** приложение открывается, CSS загружается.

**Фактический результат:** `500 Internal Server Error`,
в консоли `Invalid PostCSS Plugin found at: plugins[0]`,
белый экран.

**Причина:** Vite находил `postcss.config.mjs` в родительской папке
`Downloads`, который ссылался на отсутствующий `@tailwindcss/postcss`.

**Исправление:** проект запускается из чистой директории;
при необходимости — добавить `css: { postcss: {} }` в `vite.config.js`.

**Статус:** Исправлен (изоляция окружения), проверен.

## BUG-008. Повторная отправка отклика возможна при двойном клике

| Поле | Значение |
|---|---|
| **Приоритет** | Major |
| **Серьёзность** | Средняя |
| **Окружение** | backend-2-practice, FastAPI |

**Шаги воспроизведения**
1. Отправить `POST /api/appointments` дважды с одинаковым телом
   и интервалом менее длительности услуги.

**Ожидаемый результат:** вторая запись отклонена с `409 Conflict`.

**Фактический результат:** при очень близких запросах проверка
конфликта не успевала сработать из-за отсутствия блокировки
(в учебной версии данные в памяти — гонок нет, но при переходе
на реальную БД проблема станет актуальной).

**Исправление (предупреждение):** в коде оставлен комментарий
о необходимости транзакционной блокировки при переходе на БД;
для SQLite добавлен `RESTRICT` на удаление услуги.

**Статус:** Принят как риск, внесён в отчёт.
