## 1. Объект и объём тестирования

| Артефакт | Что проверялось |
|---|---|
| `frontend-1-practice` | Вёрстка страницы выбора даты и времени (HTML + CSS) |
| `frontend-2-practice` | Интерактивность на нативном JavaScript |
| `frontend-3-practice` | Переписывание на React (useState, компоненты) |
| `frontend-4-practice` | React + имитационный сервер (fetch, состояния загрузки) |
| `backend-1-practice` | Базовый Python: типы, коллекции, классы, ошибки |
| `backend-2-practice` | REST API на FastAPI |
| `backend-3-practice` | Модели SQLAlchemy, связи, миграции Alembic |
| `backend-4-practice` | Валидация Pydantic, APIRouter |

**Что входило в объём:** функциональность, UI, адаптивность,
валидация, обработка ошибок, доступность с клавиатуры, API-контракты,
целостность данных в БД.

**Что не входило:** нагрузочное тестирование, пентест,
тестирование платежей (не реализованы), тестирование под Safari
и мобильные ОС.

## 2. Подход

- **Ручное тестирование** интерфейса по чек-листу (38 пунктов)
  и 15 тест-кейсам.
- **Автотесты API** — 35 проверок для `backend-2` и 29 для `backend-4`
  через `fastapi.testclient`.
- **Валидация кода** — W3C HTML Validator, проверка баланса CSS.
- **Проверка кода на типичные ошибки** — наличие инлайн-стилей,
  табличной вёрстки, `!important`.

## 7. Рекомендации

1. **Убрать захардкоженные даты.** Сейчас «сегодня» фиксировано
   (`2026-11-19`) — на реальной дате тесты будут падать.
   Нужно брать `new Date()` или данные с сервера.
2. **Добавить блокировку на уровне БД** при создании записи
   (BUG-008) — `SELECT ... FOR UPDATE` или уникальный индекс
   на `(master_id, starts_at)`.
3. **Покрыть автотестами UI** — Playwright или Cypress для сценария
   записи целиком, а не только API.
4. **Добавить CI** — GitHub Actions: линтер, тесты API, валидатор HTML
   на каждый push.
5. **Проверить на реальных устройствах** — iOS Safari, Android Chrome,
   так как сейчас адаптивность проверена только эмуляцией.
6. **Сделать эталонный макет** в Figma и автоматизировать
   визуальную сверку (скриншот-тесты).
