# Задание 4.1 (часть 1) — Декомпозиция функционала и требования

**Объект:** «Барбершоп БРИТВА» — сценарий записи клиента
(выбор услуги → выбор даты и времени → подтверждение).
**Основание:** задание 4.1, п. 1. Предыдущий список требований —
из задания 1.1 (сопроводительные README модулей Frontend/Backend).

Декомпозиция выполнена по уровням: **модуль → компонент → атомарный
компонент / действие**. По каждому листу дерева сформулировано требование
с ID `REQ-NN`. Требования сгруппированы по модулям из карты.

---
